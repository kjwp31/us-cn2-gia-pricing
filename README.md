## CN2、CN2 GT、CN2 GIA 不是一个东西

搜“美国CN2云服务器”时最容易踩的坑，就是把这三档混为一谈。

- **CN2（GT）**：走电信 AS4809 的 GT 网络，价格便宜，但 2019 年之后拥堵明显，晚高峰体验和普通 163 骨干网差距不大。
- **CN2 GIA**：同样走 AS4809，但走的是 GIA（Global Internet Access）等级，电信给了独立传输通道。搬瓦工官方的说法是“CN2 GIA 是传输中国方向数据最贵的方式”，IP transit 市价最高能到 120 美元/Mbps，这也是这类服务器比普通 VPS 贵的直接原因。
- **CN2 GIA-E（E-Commerce）**：搬瓦工把洛杉矶 DC6/DC9 的 GIA 线路打包进电商级套餐，电信走 CN2 GIA（AS4809），移动走 CMIN2（AS58807），联通走精品网（AS10099），三网回程全优化，带宽 2.5Gbps 起步。

市面上有些标注“CN2”的便宜 VPS 实际走的是 GT 档甚至只在电信单线优化，移动联通回程还是普通线路。判断方法也简单：分别用三家运营商的网络 ping 服务器 IP，再跑一次回程路由追踪，看电信方向是否落在 AS4809 的 GIA 段。下单前用这个方法验证一遍，比看宣传页靠谱。
